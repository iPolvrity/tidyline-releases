# Tidyline

Tidyline cleans up what developer tools leave behind on a Mac: Xcode Derived Data, simulators, package caches, agent worktrees and more. Everything goes to the Trash, nothing is removed without your confirmation.

This repository holds only the builds and the update feed. Requires macOS 14 or later.

## Install

1. Download the DMG from the [latest release](https://github.com/iPolvrity/tidyline-releases/releases/latest).
2. Open it and drag Tidyline to Applications.

Every build is signed with a Developer ID and notarized by Apple. Tidyline checks for updates itself (Tidyline › Check for Updates…); updates are signed and verified before they are installed.

## Установка

1. Скачайте DMG из [последнего релиза](https://github.com/iPolvrity/tidyline-releases/releases/latest).
2. Откройте его и перетащите Tidyline в «Программы».

Каждая сборка подписана Developer ID и нотаризована Apple. Обновления Tidyline проверяет сам (Tidyline › Проверить обновления…), подпись обновления проверяется перед установкой.
